# Farmer Guide

This guide explains how to use CropFusion to get crop recommendations and
yield predictions for your fields.

## Getting started

1. Open the CropFusion app in your browser (or install it as a PWA from the
   browser menu for offline access).
2. Create an account with **Register** (email + password) and log in.
3. Save your fields under **My Locations** so predictions are one click away.

## Getting a recommendation

1. Go to **Predict**.
2. Drop a pin on the map at your field location (or select a saved location).
3. Optionally set the **year** and **season** (e.g. Kharif or Rabi).
4. Press **Predict**.

CropFusion returns:

- **Recommended crop** with confidence and alternative crops.
- **Expected yield** for the top crops.
- **Why?** - a plain-language explanation of the factors that drove the
  recommendation (rainfall, temperature, soil, vegetation index).

## Understanding the explanation

The explanation tells you which inputs mattered most. For example, it may say
"Paddy is recommended because rainfall and the vegetation index for this
region are favourable." Use this to sanity-check the recommendation against
what you know about your field.

## History

Every prediction is saved to your **History**. You can:

- Revisit past recommendations.
- Search by crop, season or confidence.
- Compare seasons side by side.

## Notifications

You will receive notifications for:

- New predictions matching your saved locations.
- Warnings when conditions for a season look unusual.
- Account security events (login, password change).

## Safety notes

- Recommendations are advisory. Always combine them with local knowledge,
  official advisories, and field observations.
- Predictions include a **confidence** value; treat low-confidence results
  with extra care.

## Common tasks

| Task | Where |
|---|---|
| Add / edit a field | My Locations |
| Get a prediction | Predict |
| See past results | History |
| Update profile | My Profile |
| Change password | My Profile > Security |
