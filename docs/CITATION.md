# Citing CropFusion

If CropFusion contributes to your research or product, please cite it:

```bibtex
@misc{cropfusion2026,
  title        = {CropFusion: Precision Agriculture Decision Support},
  author       = {CropFusion Contributors},
  year         = {2026},
  howpublished = {\url{https://github.com/{owner}/cropfusion}},
  note         = {Multimodal crop-yield prediction, spatial analysis and ML
                  quality monitoring. Apache-2.0.}
}
```

## Additional references

- Software design document: `docs/SOFTWARE_DESIGN_DOCUMENT.md`.
- Model architecture: `research/MODEL_ARCHITECTURE.md`.
- Dataset statistics: `research/dataset_stats.json` and `research/DATASETS.md`.
- Phase completion reports: `docs/PHASE{2..11}_COMPLETION_REPORT.md`.

## Datasets

Source datasets are distributed via their original providers (e.g. ICRISAT).
Check each provider's terms before redistribution; the CropFusion repository
tracks the source metadata under `services/dataset_manager` and
`research/DATASETS.md`.
