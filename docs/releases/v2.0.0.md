# CropFusion 2.0.0 - Release Notes

**Date:** 2026-08-15
**Version:** 2.0.0 (see [VERSION](../../VERSION))
**Release artifacts:** `releases/v2.0.0/` (and `releases/latest/`)

## What's new

CropFusion 2.0.0 ships a freshly trained model from the **Dakshina Kannada
dataset stage** (`cropfusion-train`, Kaggle run **v6**, completed
2026-08-11, 74 accepted observations). The checkpoint was exported to
TorchScript and ONNX and assembled into the Prediction Platform's
`cropfusion_release-v2.0.0/` package.

> NOTE ON PROVENANCE (R5.2 audit, Task 10): an earlier version of these notes
> attributed this release to the later `cropfusion-train-dk-bridge` run
> (2026-08-14, 275 accepted observations). That attribution was WRONG. The
> shipped model's registered metrics (`crop/support = 11`, accuracy 0.909,
> yield R2 = 0.9748, registered 2026-08-11T10:16:31Z) match the train-v6 run
> exactly, and do NOT match the dk-bridge evaluation (`crop/support = 0`,
> yield R2 = -78019). The dk-bridge run has NOT been released; its final-epoch
> checkpoint records NaN validation metrics (see R5.2 audit, Task 10).

### Training highlights

- **Source:** `gojosensa/cropfusion-train` (Kaggle, kernel version 6).
- **Accepted observations:** 74.
- **Epochs:** 30.
- **Evaluation (test split, n=11):**
  - yield RMSE: 0.1470
  - yield MAE: 0.0966
  - yield MSE: 0.0216
  - yield R2: 0.9748
  - crop accuracy: 0.909 (top-5 1.000); crop/support = 11
- **Feature order:** Area, Rainfall, Temperature, Humidity, price
  (`input_dim = 5`).
- **Crop classes (5):** Coconut, Blackgram, Coffee, Cardamum, Pepper.

## Known issues

- **Crop classification head** was trained on a small labeled set (74
  observations; 11 crop-labeled test samples). Metrics reflect only those 11
  samples.
- **dk-bridge model NOT released:** the later dk-bridge run (275 obs) was
  audited under R5.2 and its final-epoch checkpoint records NaN validation
  metrics; no dk-bridge model has been shipped. See the R5.2 report.
- **Yield target scale mismatch (training-data defect):** some experimental
  corpora mix district-level `Yield_Proxy_NPP` (DK_Features, ~0.5-1.5) with
  village-level kg/ha yields (data_season, 62-73730) into one StandardScaler;
  metrics are then on the standardized scale and NOT comparable to absolute
  kg/ha error. See R5.2 audit (Task 5/7) for the full analysis.
