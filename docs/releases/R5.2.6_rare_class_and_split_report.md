## PART I -- Evaluation Policy

### Recommended Primary Evaluation: Spatial Leave-One-Taluk-Out Cross-Validation

**Rationale**:
1. Government data covers only 2020-2021 (single Kharif season). Temporal generalization cannot be tested.
2. 5 taluks provide natural spatial groups. Each taluk can serve as test set once.
3. Taluk-level separation guarantees zero spatial leakage.
4. Tests whether the model generalizes across geographic sub-regions within DK.

**Protocol**:
- 5-fold CV: each fold holds out one taluk for testing
- Report: per-taluk accuracy, macro-F1, per-class precision/recall/F1
- Aggregate: mean and std across 5 folds

### Supplementary Evaluation: Temporal (Limited)

- Train on 2020, test on 2021
- Only 582 test samples (coconut + pepper only)
- Reports: temporal generalization signal for coconut and pepper
- **Cannot** claim multi-year generalization

### Metrics to Report

1. **Overall**: accuracy, macro-F1, weighted-F1
2. **Per-class**: precision, recall, F1 (for coconut, pepper, coffee; cardamom/blackgram reported separately with caveat)
3. **Per-taluk**: accuracy, macro-F1
4. **Temporal**: coconut/pepper accuracy on 2021 test set
5. **Confusion matrix**: 5x5 (or 3x3 if excluding cardamom/blackgram from primary metrics)

- **Action**: INCLUDE in per-class metrics with caveat: "limited samples (n=11)"
- **Training**: Retain in training set with class-weighted loss
- **Rationale**: 11 samples across 9 villages, 4 taluks provide some spatial diversity, but single-year limits evaluation confidence
- **Future**: Collect more official observations if possible

### Coffee (101 samples)

- **Action**: INCLUDE in all metrics
- **Training**: Use class-weighted loss to prevent under-representation
- **Rationale**: 101 samples across 41 villages, 4 taluks provide meaningful training signal and marginal evaluation capacity
- **Future**: Additional observations would improve reliability

### Training Strategies (Not Implementing Yet)

1. Class-weighted cross-entropy loss
2. Focal loss (gamma=2.0, alpha=class weights)
3. **NO** oversampling, **NO** synthetic augmentation
4. **NO** class merging (coffee arabica/robusta remain as "coffee")
5. **NO** SMOTE on raw multimodal samples
