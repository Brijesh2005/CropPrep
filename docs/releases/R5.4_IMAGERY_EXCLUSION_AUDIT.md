### Root cause of the bulk exclusions
The matcher (`stam.matcher.match_images`) filters imagery by the season window of the survey year. The graded survey data covers only **2020 and 2021**:

- **Kharif 2020** → window `2020-06-01..2020-10-31`, imagery present (`2020-10-28`) → resolves.
- **Kharif 2021** → window `2021-06-01..2021-10-31`, **imagery present = NONE** (2021 only has 04-01 and 05-01, both before Jun 1) → **every Kharif-2021 observation is an empty imagery sequence and is excluded.**

This is a **dataset coverage gap**, not a matcher/CRS bug. The `patch_matcher_coord_transform.py` fix (`matcher.py:506`, `stam.py:526` reprojects into raster CRS) is applied, so coordinate/CRS errors are not the cause of the current exclusions. There is simply no 2021 Kharif-season raster to match, and (per constraints) I did **not** fabricate or zero-fill one.

Excluded class `blackgram` (2 rows, both Sullia) is a class-schema exclusion, unrelated to imagery.
