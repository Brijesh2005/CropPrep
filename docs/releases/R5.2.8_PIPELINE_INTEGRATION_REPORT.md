## MULTIMODAL RESOLUTION

For every loaded sample, the pipeline resolves:

| Modality | Source | Verification |
|----------|--------|-------------|
| Tabular context | Frozen CSV (fields dict) | `obs.tabular.fields` is dict |
| Satellite imagery | STAM `build_observation()` (NDVI/EVI paths) | `obs.sequence.pairs` populated |
| NDVI | STAM sequence builder | `obs.sequence.ndvi_paths` |
| EVI | STAM sequence builder | `obs.sequence.evi_paths` |
| Temporal info | Frozen CSV (year, season) | `obs.temporal.year`, `obs.temporal.season` |

**Important**: STAM is used ONLY for imagery resolution (NDVI/EVI path lookup).
It does NOT re-run spatial matching or override crop labels. The frozen corpus
membership is determined entirely by the CSV + manifest.

If STAM imagery resolution fails for a sample (e.g. missing imagery), an empty
`SequenceInfo` is returned and the observation still enters training (tabular
branch can still train). This is the correct degradation behavior.
