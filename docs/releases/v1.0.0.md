# CropFusion 1.0.0 - Release Notes

**Date:** 2026  
**Version:** 1.0.0 (see [VERSION](../../VERSION))

## What's new

CropFusion 1.0.0 is the first stable release. It packages the Phase 1-11
platform (dataset management, spatial alignment, preprocessing, multimodal
models, training, explainability, enterprise backend, frontend SPA, ML quality,
observability) with a complete deployment, MLOps and documentation layer.

### Highlights

- **Multimodal crop-yield model** - TabTransformer + Dual CNN (NDVI/EVI) +
  temporal Transformer + cross-modal gated fusion.
- **Enterprise backend** - modular FastAPI monolith: auth + RBAC (Argon2id,
  JWT), predictions, history, notifications, explainability, GIS, model and
  dataset registries, audit logging.
- **Frontend** - React 19 PWA with maps, history, admin dashboards.
- **ML quality** - drift (feature/label/prediction/spatial/temporal),
  fairness, monitoring exporters, optimization (ONNX/TorchScript/quantization).
- **MLOps** - model registry, promotion gates, rollback, experiment tracking,
  scheduled drift/fairness monitoring, release reports.
- **Deployment** - Docker Compose (dev + prod), Caddy TLS, Prometheus,
  Grafana, Loki, automated backups.
- **CI/CD** - GitHub Actions for lint, tests, coverage, containers, security,
  release and deploy. Dependabot enabled.
- **Documentation** - full guide set, user manuals, research assets, website
  content.

### Compatibility

- Python >= 3.12; Node >= 20; Docker Compose v2.
- Backend defaults to SQLite for development; PostgreSQL + PostGIS for
  production.

## Known issues

- `torch.compile` requires a C compiler; without one, execution falls back to
  eager mode automatically (expected on stock Windows/many CI runners).
- The standalone `inference` replica is profile-gated (`gpu`) and only needed
  for horizontal scaling.
