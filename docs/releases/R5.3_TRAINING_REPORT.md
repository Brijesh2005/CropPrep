## YIELD LOSS SAFETY (VERIFIED)

The MultiTaskLoss handles yield_value=None safely:

1. Preprocessor outputs `yield_label=0.0` and `yield_unit_mask=False` for samples without valid kg/ha yield
2. `MultiTaskLoss.per_task_losses()` calls `_drop_non_kg_ha_targets()` which uses `yield_unit_mask` to exclude non-kg/ha samples from the Huber regression loss
3. Result: yield loss is only computed on samples with valid physical yield targets
4. The frozen crop corpus has yield_value=None for all 10,674 samples (classification only)
5. Yield head receives zero gradient from the frozen crop corpus — correct behavior for R5.3

- P100 supports FP16 (compute capability 6.0)
