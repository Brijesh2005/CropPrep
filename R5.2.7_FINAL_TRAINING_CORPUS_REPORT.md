### Provenance Resolution

The existing labeled corpus from `data_season.csv` is **not included** in the final training manifest because:

1. **No precise GPS coordinates** -- only city-level location names
2. **Unverified satellite coverage** -- STAM matching not re-run
3. **Different era** -- data from 2004-2019 (vs. government 2020-2021)
4. **Incomplete provenance chain** -- cannot trace each observation through the full matching pipeline

The government corpus (10,674) has full provenance:
```
API (kodi.karnataka.gov.in) -> JSON download -> Label normalization
-> Spatial matching (DK_Features grid, 5km tolerance)
-> Temporal matching (15-day tolerance)
-> Tabular matching (district_grid)
-> Satellite verification (Sentinel-2 NDVI/EVI)
-> Deduplication -> Crop label validation
```

### The 74-Count Explanation

The original "74 crop training samples" refers to:
- 204 rows in `data_season.csv` filtered to 2018-2019
- 74 of those survived STAM satellite matching
- This was the **original** training set before government data integration
- The government corpus (10,674) now supersedes this
