## 2. Verified findings

### 2.1 Task 2 - corpus collapse root cause (CONFIRMED)

- Grid = 284 locations x 60 years (1966-2025) x 3 seasons = **51,120 cells**.
- Imagery catalog covers **2018-2025 only**. All pre-2018 cells are
  structurally unresolvable: no images - no temporal observations -
  `ST-Q-IMG-001` + `ST-Q-TEMP-002` on 50,138 cells.
- Accepted: **275** (0.54%); rejected: **50,845**. Quality gate
  (`fail_below=40`) is **never** the binding constraint - every rejection
  carries a data-absence issue. No threshold loosening can help.
- Accepted years: 2018-2023; seasons Kharif=201, Zaid=45, Rabi=29;
  74 village-level (data_season, kg/ha) + 201 district-level (DK_Features,
  NPP proxy).

### 2.2 Task 3 - multimodal input (VERIFIED)

- Tabular tensor: 7-dim (5 numeric standard-scaled + 2 ordinal categorical),
  finite for all 275, contract matches `model.yaml`.
- **CRITICAL:** 201/275 (73%) DK_Features samples carry only synthetic fields
  (`feature_columns: []`); through `TabularPipeline` every field is mean-filled
  - **all 201 get the identical vector** `[0.1604, 0.0, 0.502, 0.0, 0.0, 2, 2]`.
  Only 13 unique tabular vectors across 275 samples.
- Crop labels: 5 classes, 74 labeled samples only (201 None).

### 2.3 Task 4 - NaN instability (ROOT CAUSE + FIX)

- Repro (`repro_loss_finite.py`, real model + real `MultiTaskLoss`): the
  tabular+label path is **finite on every split**. The NaN **cannot** come
  from tabular/labels; it originates in the **image branch** (EfficientNetV2-S
  @224px, fp16 AMP, P100) - matching the run log (`NaN detected; skipping step
  epoch=2 step=6`, val_loss NaN from ~epoch 6).
- Root-cause factors:
  1. `nan_policy: skip` (default) **silently skipped NaN steps**, exited 0,
     and picked a "best" checkpoint at epoch 11 despite NaN activity.
  2. fp16 AMP on P100 - classic overflow with near-constant 0.16/0.5 inputs.
  3. No per-tensor NaN diagnostics captured; validator logged NaN val_loss
     silently.
- **Fix applied (fail-loudly):**
  - `config.py`: default `nan_policy: skip -> stop`; `training.yaml` updated.
  - `trainer.py`: `_collect_nan_diagnostics()` records per-tensor NaN/Inf
    counts + non-finite-grad parameter names; `nan_steps`/`nan_diagnostics`
    surfaced in `TrainingResult.summary()`.
  - `validator.py`: accepts `nan_policy`; a NaN/Inf **validation loss** now
    raises `ValidationError` (metric-only NaN, e.g. R2 on constant targets, is
    intentionally NOT a failure).
  - Tests: 2 added; full training suite 158 passed.

### 2.4 Tasks 5/7 - yield-target scale (DEFECT + DIAGNOSTICS)

- Raw yield by level: district (NPP proxy) 0.53-1.54, n=201; village (kg/ha)
  62-73,730, n=74 - combined dynamic range **1.4x10^5**.
- One `StandardScaler` over all 275: mean 7940.86, scale 20481.18 - **all 201
  district samples scale to -0.3877 (std 0.0)**; only 14 distinct scaled values
  total (5.1%). The yield head has no signal for 73% of the corpus.
- Scaler choice cannot fix it (village-only fit still collapses district) -
  the units must not be mixed.
- Fix: `LabelPipeline.fit` computes `yield_scale_stats` + warnings (mixed-units
  flag, collapse flag), surfaced in summary/sources.json + `verify_yield_scale.py`.
- Recommendation (deferred, data decision): village-only target, per-level
  scaler/head, or calibrated proxy scaling. Do NOT mix.

### 2.5 Task 6 - temporal-split composition (VERIFIED + DIAGNOSTICS)

- train=187 (2018-2021), val=40 (2022), test=48 (2023). No leakage.
- val/test: **0 crop labels**, **1 unique tabular vector each**, standardized
  yields constant to ~4 decimals - crop metrics undefined; **R2 = -78,019 /
  -143,127 is a near-constant-target artifact (ss_tot ~ 1e-9), NOT model
  divergence**.
- Fix: `split_observations` now runs `_diagnose_split_composition`, logging
  WARNINGs; 6 tests added. Splitter is correct - the defect is the dataset.
  **Do NOT loosen the split.**

### 2.6 Task 9 - release metadata (ROOT CAUSE + FIX)

- `package_sources.py` - `_resolve_db_path` looked for
  `manager.metadata_db_path` / `metadata_db`, which `DatasetManager` never
  exposed - `INF-DS-001` on every build, cascading to zero metadata artifacts
  in the release.
- Fix: public `DatasetManager.metadata_db_path()`; hardened `_resolve_db_path`
  (manager API - `settings.metadata_db_path()` - `metadata_repository.db_path`,
  first existing wins). 6 new tests.
- The shipped v2.0.0 package now loads strictly: all 4 metadata files present,
  sha256 match, `metadata.db` provenance = backfill.

### 2.7 Task 10 - checkpoint provenance (CRITICAL)

- `latest.pt` (dk-bridge, 684.8 MB): loads cleanly; **1803 tensors,
  57,127,733 params, 0 non-finite weight tensors** - the FINAL-epoch weights
  are fully finite. But its stored metrics are **NaN**: `val_loss`, `yield/rmse`
  etc. all NaN at epoch 26. The final checkpoint was saved with NaN validation
  metrics (the old `nan_policy: skip`).
- dk-bridge `best.pt` (epoch 11) is finite per pipeline.json but not present
  in the local sync (only latest.pt downloaded).
- **The shipped v2.0.0 release model is the TRAIN-V6 model (11-Aug, 74 obs,
  11 crop-labeled test samples), NOT the dk-bridge model (14-Aug, 275 obs)**
  that `docs/releases/v2.0.0.md` claimed. Provenance evidence: release
  `metrics.json` registered 2026-08-11T10:16:31Z with crop/support=11, acc
  0.90909, yield R2 0.9748 - byte-for-byte the train-v6 evaluation. dk-bridge
  eval is crop/support=0, R2 -78,019 - no match.
- Shipped TorchScript `model/cropfusion.pt` sha256 = manifest checksum
  (ad85f717...) - file integrity OK; the DOCUMENTATION attribution was wrong.
- Forward-pass sanity: the released model runs, outputs finite, 5 crop classes,
  512-dim shared representation. `docs/releases/v2.0.0.md` corrected to
  attribute the model to train-v6.
