## 2. Feature schema (preprocessing.yaml, verified in CSV)

- **28 numeric** features: `lat`, `lon`, `spatial_match_distance_km`, `year`, `annual_rainfall_mm`, `dewpoint_c`, `elevation`, `temperature_c`, `relative_humidity_pct`, `slope`, `ndvi`, `evi`, `ndwi`, `ndre`, `savi`, `s2_obs_count`, `soil_clay_pct`, `soil_sand_pct`, `soil_organic_carbon`, `soil_ph`, `soil_moisture`, `kharif_ndvi`, `kharif_evi`, `kharif_ndwi`, `rabi_ndvi`, `rabi_evi`, `rabi_ndwi`, `env_match_distance_m`
- **4 categorical**: `season`, `is_cropland`, `land_cover_class`, `soil_type_class`
- All 32 feature columns are present in the enriched CSV (no schema mismatch).

### Quality flags found (feed Step 15 NaN/quality investigation)

- `env_support` is **constant = 1** across all rows (drop candidate; currently unused).
- `is_cropland` is **0 for 10,637 / 10,675 rows** = invert/meaning check needed.
- **EVI magnitudes are anomalous**: `evi` mean 2.17 (max 4.53), `kharif_evi` range -187..6744 (typical S2 EVI is -1..1.5). Mitigated by IQR clipping + standard scaling, but the raw source scaling must be explained.
- Soil columns carry explicit scales (ph x10 => 5.4..6.1, sand/clay x10, organic-carbon x100) - standard-scaler absorbs these; document before reporting coefficients.
- Match distance: min 0.92 m, max 1548 m, mean 164 m (excellent DK-grid proximity).

## 3. Training configuration snapshot

- AdamW LR 1e-4 (backbone x0.3 = 3e-5), WD 1e-4, warmup_cosine (2 warmup), 30 epochs, batch 16, seed 42, AMP fp16 on GPU.
- Loss: focal gamma 2.0, label smoothing 0.15, class-weight sqrt_inv; crop 0.75 / yield 0.25 (huber).
- Early stop `crop/macro_f1` (max, patience 5, restore best); checkpoints keep_last 3; NaN policy = stop.
- Model cropfusion_v1 v2.0.0: EfficientNetV2-S 224 dual NDVI/EVI, TabTransformer(6/8/512), TemporalTransformer(4/8, d=256, max_len 16), CrossModalFusion(4), GatedFusion, shared transformer, crop head(5), yield head.

## 5. Environment reality check

- Windows + CPU-only torch 2.13.0 (no CUDA); sklearn 1.8.0 and xgboost 3.3.0 available; lightgbm absent.
- **No Sentinel-2 rasters locally** (metadata.db ~0.07 MB, ~5 records) => image-patch sequences resolve empty for every observation.
- Consequence: **real multimodal (vision) training cannot run on this machine.** It requires the Kaggle GPU workspace with the attached imagery dataset.
